# Cynbit Full Stack Developer Internship Assessment

## My role
I am a BCA student specialising in AI.
I am still learning full-stack development.
Explain technical concepts in beginner-friendly language.

## Project requirements
- Build a meaningful improvement to Cynbit's existing website.
- Produce a working, responsive prototype.
- Use clean, maintainable code.
- Provide a working GitHub repository and deployed demo.
- Prepare accurate technical documentation.

## How you should work
1. First inspect the existing project and understand its structure.
2. Do not start coding until the proposed feature and architecture are approved.
3. Break implementation into small, manageable stages.
4. Explain what each important file and code section does.
5. Ask before installing unnecessary dependencies.
6. Ask before destructive commands or deleting files.
7. Never invent test results or claim something works without testing.
8. Keep the code understandable enough for me to explain in an interview.

## Security
- Never expose API keys, passwords or secrets.
- Never commit .env files.
- Keep private credentials on the server.
- Validate user input.
- Explain security-sensitive changes before making them.

## Important
Do not deploy, push to GitHub, or make external changes without asking me first.
